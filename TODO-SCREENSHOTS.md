## Image Creation Guidelines

### Technical Requirements

- **Format**: PNG (as referenced in markdown)
- **Resolution**: High enough for clarity (suggest 1920px width minimum)
- **File Size**: Optimize for web (aim for <500KB per image)
- **Naming**: Follow the exact naming convention referenced in the markdown

### Storage Location

- Create an `images/` or `assets/` directory in the project root
- Update markdown references to include the proper path (e.g., `![Alt text](../images/chapter2-ink-website.png)`)
- Or configure Jekyll to serve images from a specific directory

### Content Guidelines

1. **Clean Interface**: Close unnecessary windows/tabs before capturing
2. **Consistent Theme**: Use same OS/app theme across all screenshots
3. **Annotations**: Consider adding arrows or highlights where helpful
4. **Privacy**: Ensure no personal information is visible
5. **Branding**: Use appropriate version of Inky Editor (latest stable)

1. **Priority 1 (Chapter 2)**: Create all 6 screenshots - these are essential for the tutorial workflow
