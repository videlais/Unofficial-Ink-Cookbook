# Accessibility Statement

The Unofficial Ink Cookbook is committed to providing an accessible learning experience for all readers.

## Standards Compliance

This textbook strives to meet or exceed WCAG 2.1 AAA accessibility standards through:

- Semantic HTML structure
- Keyboard navigation support
- Screen reader compatibility
- High contrast color schemes
- Responsive design for all device sizes
- Clear and consistent navigation
- Alternative text for all images
- Readable typography with appropriate sizing

## Accessibility Features

- **Skip Navigation**: Quick links to jump to main content
- **Keyboard Navigation**: All interactive elements are accessible via keyboard
- **Screen Readers**: Proper ARIA labels and semantic markup
- **Dark Mode**: Automatic dark mode support based on system preferences
- **Reduced Motion**: Respects user preferences for reduced motion
- **Touch Targets**: Minimum 44x44px touch targets for mobile accessibility

## Reporting Issues

If you encounter any accessibility barriers while using this textbook, please report them by:

1. Opening an [issue on GitHub](https://github.com/videlais/Unofficial-Ink-Cookbook/issues)
2. Providing details about the accessibility issue encountered
3. Including information about your assistive technology (if applicable)

We are committed to addressing accessibility concerns promptly.

## Code Examples

All code examples in this textbook are provided in plain text format and can be easily copied using assistive technologies. Code blocks include proper syntax highlighting and maintain readability in both light and dark modes.

## Continuous Improvement

We regularly review and update this textbook to improve accessibility. Your feedback helps us make this resource better for everyone.
